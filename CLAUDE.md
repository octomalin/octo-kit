# octo-kit

Kit de démarrage Claude Code en français : modèles de `CLAUDE.md` (`templates/`) et skills (`skills/<nom>/SKILL.md`).

## Règles

- Tout est rédigé en français clair, phrases courtes, tutoiement dans les README.
- Un modèle de `CLAUDE.md` tient en moins de 60 lignes ; les zones à remplir sont entre `[crochets]`.
- Une skill = un dossier contenant un `SKILL.md` avec un en-tête YAML (`name`, `description`) ; la description dit QUAND l'utiliser.
- Pas de dépendance, pas de script : uniquement du Markdown.
- Toute nouveauté est ajoutée au tableau du README.
